# llm-maze

日本語 | [English](README.en.md)

LLMとの対話を、チャットではなく「歩いて探索できる3D空間」として体験する実験的なアプリです。

相談を入力すると、LLMの答えが論点・見解として部屋と道になって目の前に広がります。プレイヤーは空間を歩き、気になる道の先でさらに相談を重ねて、自分が納得できる結論を探します。

コンセプトと開発方針は [docs/CONCEPT.md](docs/CONCEPT.md)、[docs/MVP.md](docs/MVP.md)、[CLAUDE.md](CLAUDE.md) を参照してください。

## 遊び方

1. 起動すると、円形の部屋に入力欄が出ます。相談したいことを入力して Enter を押します。
2. 部屋の上に論点とLLMの暫定の答えが、各道の先の部屋に見解とその理由が表示されます。
3. 画面をクリックすると歩けるようになります。気になる道の先まで歩きます。
4. 道の先の部屋で Enter を押して、さらに考えたいことを入力します。その部屋から新しい道が伸びます。入力した問いは、道の入口に札として残ります。
5. 来た道は、振り返って歩けば戻れます。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー |
| 視点 | マウス |
| 視点操作の開始 | 画面をクリック |
| 視点操作の解除 | ESC |
| 相談の入力 | Enter(右上の「相談する」ボタンでも可) |

道の中にいる間は、WASD / 矢印キーが道の軸に沿った移動になります。マウスの向きが多少ずれていても、道から外れません。

## 起動方法

動作確認は Node.js 24 / npm 11 で行っています。OpenAI APIのキーが必要です。

```bash
npm install
cp .env.example .env
```

`.env` に OpenAI のAPIキーを設定します。

```bash
OPENAI_API_KEY=sk-...
```

開発サーバーを起動します。

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動する |
| `npm run build` | 型チェックと本番ビルドを行う |
| `npm run preview` | ビルド結果を確認する |

## 仕組み

- 相談はブラウザから `/api/think` に送られます。このエンドポイントは Vite の開発サーバーが提供するプロキシ([server/thinkApi.ts](server/thinkApi.ts))で、サーバー側で OpenAI API を呼びます。APIキーはブラウザに渡りません。そのため、開発サーバー上でのみ動作します。
- モデルは `gpt-4.1-mini` です。LLMは1行に1つのJSONを出力し、受信した行から順に空間へ追加されます。
- 最初の相談では、論点と暫定の答え、そして見解の分岐が返ります。2回目以降は、最初の論点から現在地までの流れと追加の問いを渡し、1〜3個の見解が返ります。
- 思考のツリーを部屋と道に配置する計算は [src/layout.ts](src/layout.ts) にあります。一度置いた部屋は、後から動きません。

### 構成

```text
server/thinkApi.ts   OpenAI APIへのプロキシとプロンプト
src/App.tsx          画面、相談入力、思考ツリーの更新
src/think.ts         プロキシからの応答の受信
src/layout.ts        部屋と道の配置、歩ける範囲の判定
src/World.tsx        部屋、道、文字、アニメーションの描画
src/Player.tsx       WASD / 矢印キーでの移動
src/thoughtGraph.ts  思考ノードの型
```

技術は TypeScript、React、React Three Fiber、Vite です。

## 制限

- 保存機能はありません。ページを再読み込みすると、空間は消えます。
- 1つの部屋から伸ばせる道は、最大5本です。
- 隣り合う枝の両方を深く掘ると、3階層目以降で部屋が重なることがあります。
