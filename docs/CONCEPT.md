# LLM Maze

## Concept

LLMとの対話によって生成される「思考空間」を、
プレイヤー自身が3D空間として歩きながら探索するゲーム。

プレイヤーがLLMに質問すると、
複数の仮説・論点・疑問が道や部屋として生成される。

プレイヤーはその空間を歩き、
興味のある思考経路を選択する。

さらにLLMへ質問すると、
現在地点から新しい道が生成される。

最終的にプレイヤー自身が
「この結論なら納得できる」
と判断した地点をゴールとする。


## Core Experience

「AIから答えをもらう」のではなく、
「AIと一緒に思考空間を探索する」。

## World Mapping

- 論点 → 部屋
- 仮説 → 道
- 別の選択肢 → 分岐
- 不確実性 → 霧
- 根拠が弱い推論 → 細い道
- 矛盾 → 壊れた道
- 情報不足 → 鍵のかかった扉
- 棄却された仮説 → 行き止まり
- 同じ思考の繰り返し → ループ
- 納得できる結論 → ゴール

## Important Principle

迷路は装飾ではない。

迷路の構造そのものが
LLMとの対話によって作られた思考構造を表現する。
